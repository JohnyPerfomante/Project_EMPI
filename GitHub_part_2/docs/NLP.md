# Лінгвістичний аналіз

Конвеєр працює локально у воркері. Stanza розпізнає українські слова, речення, леми, частини мови та морфологічні ознаки. Початковий провайдер Sentence Transformers використовує багатомовний MPNet із зафіксованою ревізією і вектором із 768 компонентів. [Stanza](https://stanfordnlp.github.io/stanza/available_models.html) · [Картка моделі](https://huggingface.co/sentence-transformers/paraphrase-multilingual-mpnet-base-v2)

1. API перевіряє довжину й символи, зберігає оригінальну відповідь та ставить її в чергу.
2. Воркер нормалізує Unicode, пробіли й апострофи. Для NLP окремо уніфікує регістр. Слова заперечення зберігаються.
3. Модель створює нормалізований вектор. Довгі тексти діляться за токенами на частини в межах контексту моделі, після чого вектори усереднюються. Незмінені тексти беруть вектори з кешу PostgreSQL за хешем і версією моделі.
4. pgvector обчислює точну косинусну подібність для всіх еталонів питання та їхніх затверджених варіацій. Серед однакових семантичних балів обирається більша лексична подібність Жаккара за лемами.
5. Для найближчого формулювання перевіряються фрази понять та синонімів. Покриття дорівнює сумі ваг знайдених понять, поділеній на суму всіх ваг. Правила суперечностей і термінології шукають задані викладачем фрази. Евристика заперечень зіставляє частки, ознаки й контекст у реченні.
6. Початковий бал дорівнює `0,72 × семантика + 0,08 × лексика + 0,20 × покриття`. За відсутності понять ваги двох наявних метрик перенормовуються. Бал нижче 0,39 або критичний маркер дає `LOW_MATCH`. Бал від 0,79 за наявності всіх обов’язкових понять і без попередження про нове заперечення дає `HIGH_MATCH`. Інші випадки дають `NEEDS_REVIEW`.

Пороги й ваги попередні. Висока подібність може траплятися у фактично неправильному твердженні. Евристика заперечень залежить від локального контексту, а розпізнавання спеціальних термінів залежить від еталонів, синонімів та правил. Рішення ухвалює викладач.

## Заміна моделі

Задайте `NLP_MODEL`, `NLP_REVISION`, `NLP_DEVICE`, підготуйте ваги через `python -m scripts.prepare_models` та перезапустіть воркер. Для локальної моделі без репозиторію Hugging Face вкажіть локальний шлях і змінюйте ідентифікатор версії при оновленні ваг. Сумісний провайдер реалізує `morphology` і `encode`. Нова версія має власний кеш. Воркер вимагає формат safetensors. Тестовий провайдер доступний тільки в `APP_ENV=test`.
