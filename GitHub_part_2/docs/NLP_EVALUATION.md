# Оцінювання якості NLP

На 150 україномовних прикладах для 50 питань багатомовний MPNet разом із Stanza дав **macro F1 0,520** і **accuracy 53,3%**. Модель частіше передавала неоднозначні приклади викладачу, ніж присвоювала їм високу або низьку відповідність. Мітки для цього діагностичного набору підготовлено разом із демонстраційними матеріалами. Незалежної перевірки викладачем не було.

| Очікувана категорія | Precision | Recall | F1 | Прикладів |
| --- | ---: | ---: | ---: | ---: |
| Висока відповідність | 0,958 | 0,460 | 0,622 | 50 |
| Потребує перевірки | 0,411 | 0,880 | 0,561 | 50 |
| Низька відповідність | 0,684 | 0,260 | 0,377 | 50 |
| Macro average | 0,685 | 0,533 | 0,520 | 150 |

## Матриця помилок

Рядок відповідає очікуваній категорії, стовпець — прогнозованій.

| Очікування | Висока | Перевірка | Низька |
| --- | ---: | ---: | ---: |
| Висока | 23 | 27 | 0 |
| Перевірка | 0 | 44 | 6 |
| Низька | 1 | 36 | 13 |

Один неправильний приклад отримав високу відповідність, а 36 неправильних прикладів система передала на ручний перегляд. Зі 50 правильних прикладів 27 теж потрапили до ручної перевірки. Ці результати фіксують обмеження попередніх правил і порогів на поточних матеріалах.

## Середовище та відтворення

- Apple M1 Pro, CPU, 4 потоки. Український Stanza 1.10.1 і MPNet з ревізією `4328cf26390c98c5e3c738b4460a05b95f4911f5`.
- NLP p50 **117 мс**, p95 **379,5 мс**, максимум **419 мс**. Вимір починається з векторизації відповіді після прогріву моделі й кешування еталонів. У цей інтервал не входять HTTP, черга та PostgreSQL.
- Початкові параметри вказані в [NLP.md](NLP.md). У цьому прогоні кожне питання порівнювалося зі своїм еталоном. Демонстраційні пропозиції варіацій не використовувалися.
- Повні метрики й прогнози за номерами прикладів містяться у [NLP_EVALUATION.json](NLP_EVALUATION.json).

```bash
cd backend
python -m scripts.evaluate --demo --output ../docs/NLP_EVALUATION.json
python -m scripts.evaluate --corpus /path/to/reviewed.jsonl --output /path/to/report.json
```

Незалежний корпус передається у JSONL, один об’єкт на відповідь. Приклад структури:

```json
{"question_id":"os-01","answer":"ОС розподіляє ресурси й запускає програми.","expected":"HIGH_MATCH","references":[{"text":"Операційна система розподіляє ресурси і запускає програми.","concepts":[{"concept":"ресурси"}]}]}
```

Для оцінки після калібрування зафіксуйте параметри через `--settings` і розділіть калібрувальний і тестовий набори за питаннями. Порівнюйте всі класи та окремо відстежуйте хибні `HIGH_MATCH`. Корпус для такого оцінювання має містити погоджені викладацькі мітки. Його не було у вихідних матеріалах.
