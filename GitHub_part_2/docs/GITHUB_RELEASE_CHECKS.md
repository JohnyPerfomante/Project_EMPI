# Перевірка GitHub-версії

Перевірено 7 листопада 2026 року на окремому Docker Compose-проєкті `osvitnii-protses-github` з портами 8081 і 55433. Початкове середовище не зупинялося і не змінювалося.

| Перевірка | Результат |
| --- | --- |
| Повнота копії | Усі 103 вихідні файли початкового проєкту присутні, включно з незакоміченими змінами та DOCX |
| Точність перенесення | 97 файлів ідентичні за SHA-256; адаптовано лише README, правила виключень, шаблон середовища, Compose і адресу Playwright |
| Код застосунку, міграції, банк питань, документи Word і PowerPoint | Збережені без змін |
| Docker Compose | Конфігурація валідна; образи API, воркера та вебінтерфейсу успішно зібрані |
| Стан сервісів | Міграції та підготовка моделей завершилися з кодом 0; API і PostgreSQL healthy; вебінтерфейс і NLP-воркер працюють |
| Python / Ruff | Зауважень немає для `backend` і нових скриптів |
| Backend / PostgreSQL | 35 тестів пройшли; 1 окремий тест локальної моделі пропущений у цьому запуску pytest |
| Frontend / Vitest | 10 тестів пройшли; `npm ci` успішний |
| Виробнича збірка frontend | TypeScript і Vite успішно зібрані всередині Docker |
| Playwright / реальний NLP | 7 сценаріїв пройшли: реєстрація студента й викладача, валідація, подання та перевірка відповіді, повторне використання варіації, адміністратор, мобільна навігація і зведення |
| Відновлення БД | Приватний дамп відновлено в нову порожню БД; кількості записів у всіх 22 таблицях збігаються: загалом 711 рядків на момент знімка |
| Зміст відновлених даних | Контрольні суми 21 таблиці збіглися повністю; у `system_settings` відрізнявся лише час сигналу воркера, значення налаштувань збіглися |
| Допоміжні скрипти | Configure не перезаписує `.env`; backup створює робочий дамп і відмовляється перезаписувати файл; restore успішно відновлює порожню БД та відмовляється працювати при активному API/воркері |
| Публічний архів | Містить приховані службові файли, код і документацію; робочі конфігурації, дампи, кеші, залежності та історія `.git` і тимчасові lock-файли Word не включені |

Точні контрольні суми вихідних файлів наведено у [SOURCE_PRESERVATION.json](SOURCE_PRESERVATION.json). Порядок використання — у [GITHUB.md](GITHUB.md).

Для перевірки локального NLP використано окрему копію наявного модельного кешу з тією самою ревізією MPNet та моделями Stanza. Ваги не включені до GitHub: підготовчий сервіс завантажує їх у Docker-том при першому запуску. Після відновлення дампа браузерні тести створили додаткові записи лише в тестовій GitHub-копії; приватний архів залишився знімком початкової бази до цих тестів.

GitHub Actions збережено у `.github/workflows/checks.yml`. Віддалений запуск CI відбудеться після завантаження користувачем у власний репозиторій; публікація в GitHub у межах підготовки архівів не виконувалася.
