# Інструкція користувача

## Реєстрація студента або викладача

1. На сторінці входу натисніть «Створити обліковий запис».
2. Укажіть ім’я та прізвище, електронну пошту й виберіть роль.
3. Придумайте пароль із 12–128 символів і повторіть його в полі підтвердження.
4. Натисніть «Зареєструватися». Після підтвердження створення увійдіть із власним паролем. Поле пошти вже буде заповнене.
5. Зверніться до адміністратора для призначення курсів і навчальної групи. Нові користувачі з’являються в адміністративному розділі «Користувачі».

## Студент

1. Увійдіть зі своєю електронною поштою та паролем.
2. Відкрийте «Завдання», відфільтруйте за дисципліною й виберіть питання.
3. Введіть текст і натисніть «Надіслати відповідь». Система підтвердить збереження та відкриє картку подання.
4. Перегляньте результат і рішення викладача в «Моїх відповідях». Момент показу автоматичного результату залежить від параметрів курсу.

## Викладач

1. Відкрийте «Банк питань» і створіть питання для призначеного курсу.
2. Додайте щонайменше один еталон. Для понять можна задати синоніми, вагу й обов’язковість. За наявності типових помилок додайте фразу й пояснення правила.
3. Опублікуйте питання. У «Дисциплінах» можна налаштувати видимість результатів, пороги курсу й зарахування студентів за ID, наданими адміністратором.
4. У «Перевірці відповідей» відкрийте подання. Зіставте текст студента з еталоном та рекомендацією системи. Виберіть рішення й збережіть коментар.
5. Для правильної відповіді за потреби позначте «Зберегти як затверджену варіацію». У «Базі варіацій» можна переглянути пропозиції, затвердити, відхилити або архівувати формулювання.
6. «Історія» в картці відповіді показує окремі версії аналізу й рішень. Після помилки скористайтеся кнопкою «Повторити аналіз».

## Адміністратор

1. Створіть спеціальність, дисципліну й навчальну групу у «Довідниках».
2. Створіть користувачів і призначте їм ролі. У картці курсу надайте доступ викладачам і зарахуйте студентів.
3. У «Налаштуваннях NLP» перевірте сигнал воркера, модель та параметри класифікації. Перевіряйте пороги на корпусі з викладацькою розміткою.
4. Використовуйте «Журнал аудиту» для перегляду змін. Для обмеження доступу відкличте зарахування, призначення викладача або заблокуйте обліковий запис.
